# Throne of Glass — Spoiler-Free Companion Guide

An interactive, spoiler-free reading companion for Sarah J. Maas's *Throne of Glass*
series, made for Audrey & her book club.

It covers the recommended reading order, the *Empire of Storms* / *Tower of Dawn*
chapter-by-chapter tandem-read order, interactive maps of Erilea and the wider world,
a spoiler-free guide to the kingdoms and characters, a glossary, per-reader progress
trackers, and a separate section for *A Court of Thorns and Roses*.

## View it

Open `index.html` in any web browser. Everything is self-contained — a single HTML
file plus the images in `maps/`. No build step, no server.

## Publish it with GitHub Pages

1. In this repository on GitHub, go to **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then click **Save**.
4. After a minute or two the guide is live at
   `https://<your-username>.github.io/throne-of-glass-guide/`.

## The reading trackers

Each reader gets their own profile, saved privately in their own browser — no
accounts and no server. The "Copy my progress link" button creates a link that
carries a reader's progress to another device.
